# 💖 Just For Her

A tiny interactive corner of the internet where every click reveals a new moment. ✨

This project is a fun interactive web experience built with **HTML, CSS, and JavaScript**, featuring animated proposal screens, personalized text, background music, and interactive buttons.

## ✨ About

The project presents a series of interactive proposal screens where the experience changes based on the user's choice.

The name can also be customized through the URL using a `name` parameter.

## 🌟 Features

* 💕 Interactive multi-screen proposal experience
* ✨ Personalized name using URL parameters
* 🎨 Gradient backgrounds and styled UI
* 🎞️ Animated GIF-based visuals
* 🎵 Background music
* 🎉 Confetti effect on the "Yes" response
* 🏃 Interactive moving "No" button
* 🌈 Smooth screen transitions and animations
* 📱 Responsive layout

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Canvas Confetti**
* **Google Fonts**
